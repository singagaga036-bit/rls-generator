# rls-generator

Генератор названий РЛС СССР/РФ с подробными справками и ТТХ.

Живой сайт: https://singagaga036-bit.github.io/rls-generator/

## Что внутри
- `index.html` — страница сайта
- `style.css` — оформление (тёмный экран РМО)
- `app.js` — логика: вращающийся луч, цели на радаре и карточка станции
- `data-*.js` — база станций по темам (наземные, ЗРК, корабельные, бортовые и т.д.)

## Как добавить станцию
Открой подходящий файл `data-*.js` и впиши новую запись перед закрывающей скобкой `);`:

    {
      name: 'Название станции',
      year: 'Год',
      nato: 'Имя в НАТО',
      desc: 'Описание — можно в 2–3 предложения.',
      ttx: [
        ['Дальность', '300 км'],
        ['Шасси', 'ЗиЛ-131']
      ]
    },

Поля `nato` и `ttx` необязательные: если их нет, карточка сама их скроет.
Счётчик «В базе станций» обновится автоматически.
